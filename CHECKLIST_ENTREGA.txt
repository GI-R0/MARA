🚀 PASOS PARA INICIAR EL PROYECTO
═══════════════════════════════════════════════════════════════════════════════

1. CLONAR REPOSITORIO
   $ git clone https://github.com/GI-R0/SPORTS.git
   $ cd SPORTS

2. INSTALAR DEPENDENCIAS (BACKEND)
   $ cd backend
   $ npm install

3. INSTALAR DEPENDENCIAS (FRONTEND)
   $ cd ../frontend/sportifyclub-frontend
   $ npm install

4. CARGAR DATOS DE PRUEBA (opcional pero recomendado)
   $ cd ../../backend
   $ npm run seed
   
   Esto cargará:
   • 31 usuarios (1 admin, 5 clubs, 25 usuarios regulares)
   • 30 pistas deportivas
   • 100 reservas de ejemplo

5. INICIAR BACKEND (Terminal 1)
   $ npm run dev
   → Servidor en http://localhost:4000

6. INICIAR FRONTEND (Terminal 2)
   $ cd frontend/sportifyclub-frontend
   $ npm run dev
   → Aplicación en http://localhost:5173

7. ACCEDER CON CREDENCIALES ADMIN
   Email: admin@sportify.com
   Contraseña: Admin123!

🔄 FLUJOS PRINCIPALES
═══════════════════════════════════════════════════════════════════════════════

REGISTRO/LOGIN:
Usuario → Formulario → API → Validación → Hash password → JWT Token → 
localStorage → Axios interceptor → Todas las requests autenticadas

VER PISTAS:
Frontend → API /pistas → Backend obtiene de MongoDB → Renderiza CardPista →
Click en pista → Detalles (PistaDetail.jsx)

REALIZAR RESERVA:
Usuario selecciona pista → ReservaForm → Valida fecha/hora → Envía POST →
Backend valida disponibilidad → Crea documento Reserva → Respuesta al cliente

ADMINISTRACIÓN (clubs/admin):
Club logueado → GestionPistas → Ver sus pistas → CRUD →
Admin → AdminPanel → Ver todos los usuarios y pistas
