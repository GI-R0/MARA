🚀 PASOS PARA EJECUTAR
───────────────────────────────────────────────────────────────────────────────

1. Clonar o descargar el repositorio:
   git clone https://github.com/GI-R0/SPORTS.git
   cd SPORTS

2. Instalar dependencias del BACKEND:
   cd backend
   npm install

3. Instalar dependencias del FRONTEND:
   cd ..
   cd frontend/sportifyclub-frontend
   npm install

4. Asegurarse de que MongoDB esté accesible (ya configurada en .env)

5. OPCIONAL - Cargar datos de prueba:
   cd ../../backend
   npm run seed

   Esto creará automáticamente:
   ✓ 31 usuarios (1 admin + 5 clubs + 25 usuarios regulares)
   ✓ 30 pistas deportivas
   ✓ 100 reservas de ejemplo

6. Iniciar el BACKEND (terminal 1):
   npm run dev
   → El servidor escuchará en http://localhost:4000

7. Iniciar el FRONTEND (terminal 2):
   cd frontend/sportifyclub-frontend
   npm run dev
   → La aplicación se abrirá en http://localhost:5173

8. Acceder con las credenciales admin:
   → Email: admin@sportify.com
   → Contraseña: Admin123!
